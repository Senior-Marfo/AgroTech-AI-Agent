# Data provenance and permissions

Last checked: 26 Nov 2026. No dataset of real farms is used. No personal data is collected.

## Test scenarios (synthetic)
- Created by `evaluation/generate_scenarios.py`, seed 313, from the parameter ranges in that script.
- All rows are simulated. Planned size: 90 (30 development, 60 frozen test); reference actions are
  added by two independent labellers and a third who resolves disagreements.
- Risk: results on synthetic cases may not generalise to real farms.
